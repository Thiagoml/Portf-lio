Negado pelo Banco: Crédito Inclusivo com Dados do BCB

1º semestre · 2026

Empresa parceira
Projeto interno da FATEC São José dos Campos
Problema
Grandes instituições financeiras costumam recusar crédito a populações historicamente excluídas, porque avaliam o risco de forma tradicional e não enxergam onde existe consumo reprimido e capacidade real de pagamento. Sem dados organizados por território, quem decide a concessão não consegue identificar as regiões em que o crédito seria sustentável.
Tecnologias
Python 3, MariaDB/MySQL, Google Colab, HTML, CSS, JavaScript, GitHub
Solução
A partir do projeto RealIT, feito por veteranos da FATEC, a turma fez engenharia reversa e refatoração: auditou o fluxo de dados, atualizou as séries públicas do Banco Central (volume de crédito, inadimplência, endividamento e crescimento da carteira) e documentou o código em um notebook público no Colab. Depois, criou uma interface web responsiva para explorar os indicadores e os rankings do Score de Oportunidade.

Projeto no GitHub
Minhas contribuições
  • Criei, no notebook do Colab, o gráfico do Eixo I (risco de crédito) por estado, com filtros de período e região.
  • No notebook do Colab, remapeei, limpei e estruturei a função de tratamento para padronizar os dados por região.
